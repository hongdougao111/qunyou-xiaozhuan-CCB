## ✨ 它在玩什么

群里多了一个外汇交易账户。八种货币对，报价每 5 分钟动一次，
群友用**红豆币**开杠杆仓位，赚钱或者爆仓。

## 💥 这个插件的核心：仓位管理

外汇和股票最大的区别是**杠杆**。

你只需要交一小部分保证金，就能开一个比本金大得多的仓位：

```
1 手 = 1000 红豆币名义价值
100 倍杠杆 → 开 1 手只要 10 红豆币保证金
```

听起来很爽，但反过来：

> **价格反向走 1%，你的保证金就没了。**

所以真正决定生死的不是「你看对没看对」，而是**你开了多大仓位**。
开 0.5 手，价格走 2% 你还活着；开 5 手，走 0.2% 你就归零。

### 爆仓机制

每个行情周期检查一次：

```
权益 = 余额 + 所有持仓的浮动盈亏
占用保证金 = Σ 各仓位保证金

当 权益 < 占用保证金 × 50% → 强制平仓，余额清零
```

100 倍杠杆下，价格反向走 **0.5%** 就爆。
500 倍杠杆下，走 **0.1%** 就爆。

`/fx 仓` 里的「保证金比例」就是你的生命条：
低于 150% 会亮警告，低于 100% 就已经在爆仓线附近了。

## 🍚 低保：让游戏能继续

外汇模拟最常见的死法不是慢慢亏，是**一把梭哈然后瞬间归零**。

所以这里有一条兜底线：

> 权益低于阈值的玩家，**每天可以领一次低保**。

默认 300 以下能领 300，领完还能接着玩。
金额和阈值都能在管理面板调，设成 0 就等于关闭。

这不是慈善，是让游戏不会因为一个人爆仓而结束。

## 📋 指令

只有一个指令 `/fx`，后面跟子命令，不占指令表。

| 指令 | 作用 |
|---|---|
| `/fx` | 行情与账户概览 |
| `/fx 多 <货币对> <手数> [杠杆]` | 做多 |
| `/fx 空 <货币对> <手数> [杠杆]` | 做空 |
| `/fx 平 <编号>` | 平仓 |
| `/fx 全平` | 一键平掉全部 |
| `/fx 仓` | 我的仓位 |
| `/fx 榜` | 富豪榜 |
| `/fx 低保` | 领低保 |
| `/fx 看 <货币对>` | 单对详情 |
| `/fx诊断` | 运行状态，排查用 |

货币对支持多种写法：`USDJPY`、`usdjpy`、`USD/JPY`、`美元/日元` 都认。

杠杆不写就用默认值（100 倍）。

## 💰 交易规则

- **点差** 单边 0.012%
- **手续费** 名义价值 0.02%，开平各收一次
- **强平线** 权益 < 占用保证金 × 50%
- **单 tick 最大波动** 3%
- **隔夜利息** 每天按名义价值 0.02%，多头付、空头收

隔夜利息是防止玩家「开了仓位不管」的机制。设成 0 就关掉。

## ⚙️ 配置项

| 参数 | 默认 | 说明 |
|---|---|---|
| 行情刷新间隔 | 5 分钟 | 1-120 分钟 |
| 开户送的红豆币 | 1000 | 设 0 就只能靠低保起家 |
| 默认杠杆 | 100 | 不写杠杆时用 |
| 杠杆上限 | 500 | 500 倍下反向走 0.2% 就爆 |
| 低保金额 | 300 | 设 0 等于关闭 |
| 领低保的权益上限 | 300 | 权益低于这个数才能领 |
| 隔夜利息 | 0.02%/天 | 多头付、空头收 |

## 🚀 安装

1. 把 `astrbot_plugin_hongdou_stock` 目录放进 `AstrBot/data/plugins/`
2. WebUI → 插件 → 红豆币爆仓模拟器 → 重载
3. 群里发 `/fx`

数据存在 `data/plugin_data/astrbot_plugin_hongdou_stock/fx.json`，
卸载重装插件不会丢。

> **从 1.x 升级**：旧版是股票玩法，存档结构不兼容，会自动重置为外汇市场。
