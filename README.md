## ✨ 它能做什么

群里多了一个交易所。十只虚构的股票，价格每 5 分钟动一次，
群友用**红豆币**买卖，涨了赚、跌了亏。

```
群友：/股
Bot： 🍁 红豆股市 · 实时行情

      红豆银行 HD001    102.31  ▲+2.31%  ▂▃▄▄▅▆▇█
      尾鳍科技 HD003    271.80  ▼-3.12%  ▇▆▅▄▃▃▂▁
      ...

      你的红豆币：1000   总资产：1000

群友：/股 买 HD001 5
Bot： 买入 红豆银行 5 股 @ 102.31，花费 512 + 手续费 1 = 513 红豆币。
```

## 🍚 低保：这个插件的核心设计

模拟炒股最常见的死法不是亏钱，是**亏到一分不剩，然后彻底没得玩**。

所以这里有一条兜底线：

> 总资产（现金 + 持仓市值）低于阈值的玩家，**每天可以领一次低保**。

默认 300 红豆币以下能领 200，领完还能接着玩。
金额和阈值都能在管理面板调，设成 0 就等于关闭。

这不是慈善，是让游戏能一直有人玩下去。

## 📋 指令

只有一个指令 `/股`，后面跟子命令，不占指令表。

| 指令 | 作用 |
|---|---|
| `/股` | 行情总览 |
| `/股 买 <代码> <股数>` | 买入 |
| `/股 卖 <代码> <股数>` | 卖出（股数写 `all` 全卖） |
| `/股 仓` | 我的持仓与浮动盈亏 |
| `/股 榜` | 富豪榜 |
| `/股 低保` | 领低保 |
| `/股 看 <代码>` | 单只详情 |
| `/股诊断` | 运行状态，排查用 |

股票代码和名字都能用：`/股 买 HD001 5` 和 `/股 买 红豆银行 5` 等价。

## 💰 交易规则

- **手续费** 0.15%，最低 1 红豆币，买卖都收
- **单次涨跌上限** 12%，防止随机数把价格撕碎
- **软边界**：跌破基准价 20% 时漂移转正，涨过 500% 时转负
- **分红**：持有股票每 6 小时按市值拿 0.8%，鼓励拿住而不是天天折腾

价格模型是几何随机游走，每 tick 波动 = 日波动率 / √(一天多少 tick)，
所以「日波动率 4.5%」这个参数是能直接读懂的。

## ⚙️ 配置项

| 参数 | 默认 | 说明 |
|---|---|---|
| 行情刷新间隔 | 5 分钟 | 1-120 分钟 |
| 开户送的红豆币 | 1000 | 设 0 就只能靠低保起家 |
| 低保金额 | 200 | 设 0 等于关闭 |
| 领低保的资产上限 | 300 | 总资产低于这个数才能领 |
| 分红间隔 | 6 小时 | |
| 每次分红比例 | 0.8% | 按持仓市值 |

## 🚀 安装

1. 把 `astrbot_plugin_hongdou_stock` 目录放进 `AstrBot/data/plugins/`
2. WebUI → 插件 → 红豆股市 → 重载
3. 群里发 `/股`

数据存在 `data/plugin_data/astrbot_plugin_hongdou_stock/market.json`，
卸载重装插件不会丢。
